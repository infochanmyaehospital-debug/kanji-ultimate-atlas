KANJI ULTIMATE ATLAS — FINAL APP BUILD

Mobile-first progressive web app.

Features:
• 612-kanji N5/N4/N3 master inventory
• Search and filtering
• Individual kanji study cards
• Meaning / on'yomi / kun'yomi / vocabulary fields
• Visual family maps
• Favorites
• Learned progress saved locally
• Daily 10-character review
• Multiple-choice quizzes
• Level-specific quizzes
• Dictionary fallback
• Offline cache / PWA support

Data integrity:
The 612-character study inventory is the agreed 79/166/367 set. The JLPT no longer publishes a fixed post-2010 kanji list, so level sets are reconstructed study sets. Unverified fields remain explicitly marked rather than being presented as verified.
